# Introduction

LogWatch is an AI-powered log anomaly detection platform. Instrument your Node.js services with a one-line SDK call, and LogWatch will automatically detect unusual patterns in your log streams — from error spikes to abnormal request volumes — using a streaming IsolationForest model running in a Rust engine.

## How it works

1. **Instrument** — Add `@logwatch/node` to your service and initialise it with your API key.
2. **Stream** — The SDK intercepts `console.*` calls, batches them, and POSTs them to the LogWatch ingest endpoint.
3. **Analyse** — The Rust engine aggregates logs into 60-second per-service windows, extracts a 7-feature vector, and runs ONNX inference.
4. **Alert** — Anomalies are persisted to the database and appear on your dashboard within seconds.
